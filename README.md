# 基于 STM32 与 K210 的三合一智慧门禁系统 🚪🔑

这是一个结合了**物联网控制**与**边缘端端侧 AI 视觉**的多功能智慧门禁系统。系统采用 **STM32F103** 作为主控芯片，协调 RFID 刷卡、指纹识别、舵机锁体及菜单交互；同时使用双核 RISC-V 处理器 **Kendryte K210** 作为视觉处理器，运行神经网络模型以实现毫秒级的实时人脸识别开锁。

---

## 🌟 系统核心功能与特色

1.  **三合一多维开锁**：
    *   **RFID 射频刷卡**：基于 MFRC522 读卡模块，支持授权卡号比对与动态增删卡片。
    *   **AS608 指纹识别**：支持高精度指纹采样、特征对比、指纹模板存入指纹模块 Flash 库。
    *   **AI 人脸识别**：K210 通过本地 KPU 硬件加速器运行 YOLOv2 人脸检测和特征匹配网络，验证通过后通过串口将开锁指令传输给 STM32。
2.  **人性化交互菜单**：
    *   利用 0.96 寸 OLED 屏显示状态和设置菜单。
    *   通过 4 个板载按键，管理员可以就地录入/删除指纹、添加/注销门禁卡。
3.  **防断电数据丢失**：
    *   RFID 授权卡号存储在 STM32 内部 Flash 中，断电后卡号信息不丢失。
    *   指纹特征点存储在 AS608 指纹芯片自带的 Flash 存储器中。
4.  **安全舵机锁控制**：
    *   利用 STM32 TIM4_CH4 输出的 PWM 脉宽信号驱动伺服舵机模拟门锁。开锁后自动保持 3 秒，随后自动回弹锁死。

## 🛠️ 开发环境与工程配置

### 1. STM32 开发环境
*   **IDE**: **STM32CubeIDE** (或者 Keil MDK-ARM v5)
*   **软件库**: STM32Cube FW_F1 V1.8.7 (HAL 库驱动)
*   **打开工程**：
    *   在 STM32CubeIDE 中，通过 `File -> Import -> General -> Existing Projects into Workspace`，选择项目下的 `STM32_Project` 文件夹导入编译。

### 2. K210 开发环境
*   **IDE**: **MaixPy IDE** 或 **PyCharm** (安装 MicroPython 插件)
*   **固件**: K210 需烧录支持 KPU 人脸识别的 MaixPy 固件 (`maixpy_v0.5.0_spimodels` 或更新版本)。
*   **源文件**: K210 的代码和模型文件存放在 `K210_Project/` 目录下。

## ⚠️ 关键步骤：K210 加密模型替换指引（避坑必看）

由于 K210 芯片的安全加密限制，项目中的人脸检测与比对模型（`.smodel`）与原作者的芯片机器码进行了硬绑定。**直接将本项目现有的模型拷入你的 SD 卡将无法读取运行。**

请按照以下步骤重新申请模型加密文件：

1.  **获取你板子的机器码**：
    *   将 K210 连接到电脑，打开串口工具或 MaixPy IDE。
    *   运行以下 MicroPython 代码获取芯片唯一 Key：
        ```python
        import binascii
        from machine import unique_id
        print(binascii.hexlify(unique_id()))
        ```
    *   控制台打印出来的字符串即为你的板载**机器码 (Machine Code)**。
2.  **重新下载加密模型**：
    *   登录 [MaixHub 模型平台](https://maixhub.com/)。
    *   选择你的 K210 人脸识别模型（包含人脸检测、五点关键点、196维特征提取）。
    *   输入你刚才获取的机器码，提交并下载针对你这块芯片专属加密的 `.smodel` 文件。
3.  **部署到 SD 卡**：
    *   准备一张 FAT32 格式的 MicroSD 卡。
    *   将重新下载的三个加密模型更名为如下名称：
        *   `FaceDetection.smodel` (人脸检测模型)
        *   `FaceLandmarkDetection.smodel` (五点关键点模型)
        *   `FeatureExtraction.smodel` (特征提取模型)
    *   将它们以及 `K210_Project/boot.py` 一起拷贝至 **SD 卡的根目录**。
    *   将卡插回 K210，重新通电即可完美运行。

## 🏃‍♂️ 运行与操作指南

1.  **连接硬件**：按照上面的接线对照表将 STM32、K210、OLED、AS608、RC522、按键和舵机连接好，并确保电源**共地**。
2.  **烧录固件**：
    *   在 STM32CubeIDE 中编译 `STM32_Project`，生成 `SmartAccessControlSystem.elf` / `.hex` 文件，通过 ST-Link 下载到 STM32 芯片中。
    *   给 K210 烧录 MaixPy 固件，并插入拷有模型和 `boot.py` 的 SD 卡。
3.  **注册开锁凭证**：
    *   系统上电后，OLED 会显示欢迎页面。
    *   按 **Key1** 进入菜单设置界面。
    *   使用 **Key1** 切换选项，选择 `Add card` 或 `Add finger`，再按 **Key2** 确认。
    *   按照屏幕提示刷入你的 IC 卡或按压手指录入指纹。
4.  **解锁体验**：
    *   返回待机状态（显示 `Please unlock`）。
    *   **人脸识别**：将脸部对准 K210 摄像头。比对分值 > 80% 后，K210 通过串口向 STM32 发送信号，舵机旋转，开门 3 秒后自动闭合。
    *   **指纹识别**：按压录入的手指，指纹指示灯变绿，舵机旋转，开门。
    *   **RFID 刷卡**：将录入的 IC 卡靠近 RC522，屏幕显示卡片ID，开门。
